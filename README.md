Tarot Space
1. Общая информация о проекте
Tarot Space — веб-приложение для онлайн-гадания на картах Таро. Приложение позволяет пользователям выбирать различные виды раскладов и тематики гадания, задавать собственные вопросы, получать случайно выбранные карты с соответствующей интерпретацией, а также сохранять результаты гаданий в личной истории.
Ориентировано на пользователей, интересующихся картами Таро и желающих получать интерпретации раскладов в удобном онлайн-формате.
2. Функциональные требования
2.1. Регистрация и авторизация
•	Регистрация новых пользователей с указанием имени, логина и пароля.
•	Авторизация зарегистрированных пользователей.
•	Выход из учётной записи.
•	Просмотр и редактирование личных данных.
2.2. Проведение гаданий
•	Выбор одного из доступных видов расклада:
o	«Карта дня» — выбор одной случайной карты.
o	«Три карты» — расклад на прошлое, настоящее и будущее.
o	«Отношения» — расклад на чувства, отношение другого человека и перспективы отношений.
•	Выбор тематики гадания:
o	Любовь и отношения.
o	Работа и карьера.
o	Общие вопросы.
•	Возможность ввести собственный вопрос перед началом гадания.
•	Случайный выбор карт из всей колоды без повторений в рамках одного расклада. Выбор карт не зависит от выбранной тематики.
•	Отображение карт в закрытом виде с возможностью переворачивания по нажатию.
•	Отображение названий, изображений и интерпретаций выпавших карт.
•	Подбор интерпретации каждой карты в соответствии с выбранной тематикой и её положением (прямое или перевёрнутое).
•	Вывод общей информации о результатах расклада на основе значений выбранных карт.
•	Сохранение вопроса, тематики и результатов гадания в истории пользователя.
2.3. История гаданий
•	Автоматическое сохранение результатов раскладов в базе данных.
•	Просмотр истории предыдущих гаданий.
•	Отображение даты, типа расклада, выбранной тематики, заданного вопроса и выпавших карт.
•	Просмотр подробной информации о ранее сохранённых раскладах.
2.4. Справочник карт
•	Просмотр полного каталога из 78 карт Таро.
•	Отображение изображения, названия и описания каждой карты.
•	Просмотр базовых значений карты в прямом и перевёрнутом положении.
•	Поиск карт по названию.
3. Нефункциональные требования
3.1. Удобство использования
•	Интерфейс должен быть интуитивно понятным и иметь единый визуальный стиль.
•	Навигация между основными разделами должна быть простой.
•	Приложение должно предоставлять обратную связь при выполнении действий пользователя.
3.2. Производительность
•	Запросы к серверу должны выполняться асинхронно, без необходимости перезагрузки страницы.
•	Время обработки стандартных запросов должно быть минимальным.
•	Во время загрузки данных пользователь должен видеть соответствующий индикатор загрузки.
3.3. Надёжность и безопасность
•	Пароли пользователей должны храниться в базе данных в хешированном виде.
•	Пользователь должен иметь доступ только к собственной истории гаданий.
•	Должна выполняться проверка вводимых пользователем данных.
•	При возникновении ошибок приложение должно отображать понятные сообщения.
3.4. Работа с данными
•	Информация о пользователях, картах, тематических интерпретациях и раскладах должна храниться в базе данных.
•	Данные должны сохраняться между запусками приложения.
•	Взаимодействие клиентской и серверной частей должно осуществляться через REST API.
4. Используемый технологический стек
Frontend (клиентская часть):
•	React — разработка пользовательского интерфейса и управление его состоянием.
•	JavaScript — реализация логики взаимодействия с пользователем.
•	HTML — структура веб-страниц.
•	CSS — оформление и адаптивная вёрстка.
•	Fetch API — отправка асинхронных запросов к серверу.
Backend (серверная часть):
•	Python — основной язык программирования серверной части.
•	FastAPI — создание REST API и обработка запросов от клиентской части.
•	SQLAlchemy — взаимодействие с базой данных.
•	Pydantic — проверка и валидация данных.
•	aiosqlite — асинхронное взаимодействие с SQLite.
База данных:
•	SQLite — хранение информации о пользователях, картах Таро, тематических интерпретациях, типах раскладов и истории гаданий.
Инструменты разработки:
•	Git и GitHub — контроль версий и совместная работа над проектом.
Принцип формирования интерпретаций
Для каждой из 78 карт Таро в базе данных заранее хранятся интерпретации по трём тематикам: любовь и отношения, работа и карьера, общие вопросы. Для каждой тематики предусмотрены значения карты в прямом и перевёрнутом положении.
При проведении гадания пользователь самостоятельно выбирает тематику и вводит свой вопрос. Backend случайным образом выбирает карты из колоды, после чего подбирает для каждой карты соответствующую интерпретацию из базы данных с учётом выбранной тематики и положения карты.
Введённый вопрос сохраняется вместе с результатом гадания. Тематика определяется непосредственно пользователем, а случайный выбор карт не зависит от выбранной категории.
